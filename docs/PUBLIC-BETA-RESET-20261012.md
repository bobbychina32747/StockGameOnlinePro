# 公测重置与行情时钟修复

用户确认范围：保留账号密码，清空公测资产、订单、基金、赛季、行情和 AI，恢复初始资金。

旧行情每秒推进一个交易分钟，A 股 240 秒结束一天。连续运行八小时相当于 120 个交易日；若每天涨停，50 × 1.1^120 ≈ 4,635,453。这是时间加速与过强正反馈叠加，不能解释成真实的隔夜涨幅。旧代码还会在全市场休市时强制把分钟配置改成一秒，这个分支已删除。

生产配置：`TICK_INTERVAL_MS=60000`、`SANDBOX_FAST=false`、`FORMAL_CONTINUOUS_SIMULATION=true`。连续模拟全天开放，真实一分钟推进一个交易分钟，A 股一天需要四小时；仍是游戏时钟，不是现实交易日历。启动及重启沿用持久化的分钟计数。

行情因子和估值回归已转换为有上限的日漂移；确定性漂移总量限制为每日 ±3%，随机波动、独立新闻和跳跃另行计算。日涨跌停只约束当日相对于昨收的报价，不会在触及后把后续方向锁死。旧百万价格不会依靠长期单边下跌消化，本次按授权重新生成基础行情。

`backend/scripts/reset-public-beta.cjs` 在服务停止后创建新数据库。它保留身份、密码、会话、站点绑定、用户和固定区服账号 ID；账户所有财务及赛季字段回到 schema 初值（每区服 100,000）。其余股票游戏表为空，由新引擎初始化。博客和其他游戏云存档保留。未知表或缺少账户默认值会使脚本中止，不会直接覆盖原库。

新库验证保留表行数、外键、完整性和清空范围，再把原数据库及 WAL/SHM 同时移动至同卷 `public-beta-before-reset-20261012`，无需复制大型历史库。适配服务的旧委托幂等数据库同步留档并重新创建，防止返回重置前的委托结果。原数据不进入 Git。

执行需要显式 `CONFIRMED_PUBLIC_BETA_RESET=keep-accounts-reset-assets`；请先停止原后端和适配服务。回退也必须停止两个服务，把当前库另外留档，将备份原库及 WAL/SHM 放回原文件名，恢复部署前镜像和时钟配置。回退会恢复旧资产及旧行情问题，不能作为修复方案长期运行。

启动不再执行历史全表 GROUP BY/DELETE。历史缓存按股票和周期限量加载；同时间点的后续落库复用既有 ID，避免日结重写相同缓存时增生重复记录。旧历史离线清理不阻塞服务启动。

启动预热同时挂出可成交的做市商报价；展示深度不能填充 AI 市价单，不再让 AI 等待第十个分钟 tick。

首次上线验证：51 个区服账户恢复初始资金；三市场价格均低于 600，未再出现百万报价。公网七次分钟采样中，A 股交易日保持 30，tick 从 7201 到 7207，每次增加一；140 支 A 股均未触及涨跌停，涨跌方向分散。独立浏览器登录已有测试账号并连续运行六分半，验证 UUID 保留、初始资金、基金清空、真实 WebSocket、委托与撤单、固定区服、23 行业各至少六支、三种界面语言、缩放保留、桌面/手机布局及刷新后的登录状态；控制台错误为零。该短时验证不能保证长期行情或所有 AI 盈利。
